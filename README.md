## TFM — MSc Thesis

This repository contains the LaTeX files needed for generating the pdf of my MSc thesis/TFM. The layout is based on the [template used by David García Callejas](https://github.com/garciacallejas/Thesis) in his doctoral thesis, which in turn is based upon the [Maggi Memoir Thesis template](https://www.latextemplates.com/template/maggi-memoir-thesis).

Each of these files generates a different `pdf` layout: `tfm.tex` generates full A4 pages and includes the whole set of appendices, `tfm_noappendix.tex` generates A4 pages and does not include appendices (and lacks some of the configs), document formatting is further defined in the `structure_notrim...` file —note that the other `structure_book_08...` file is untouched from García Callejas work and was left for making code diffs easier, it is **not** used in the TFM—; in the _Chapters_ folder there is one .tex file for each chapter and configuration, and similarly for the _Appendixes_ one; finally the _Figures_ folder has obviously the figures haha.
