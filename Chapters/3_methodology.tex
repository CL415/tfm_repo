\subsubsection{Data sources}
Traffic count data was generated by the rom the COMPASS system \cite{Paag2019}, explicar columnas etc, corresponding
 to \ac{AADT} etc. The data generated corresponds to the model's base
  calculation for the year 2025.

The \ac{AADT} count data was converted to peak hour traffic volumes using
  a peak hour $k$ factor so that

\begin{equation}
    \text{Peak hour volume} = k \cdot \text{AADT}
\end{equation}
  
  The \ac{FHWA}
  states that in urban areas the $k$ value is placed towards the lower end of the $0.07-0.12$ range \cite{FHWA2018}.
  To obtain a better estimate of the factor, the \ac{AADT} values for several
    locations obtained with COMPASS were assessed against the peak hours observed from actual count data for the
    same locations. A $k$ factor of $0.075$ was found to provide close enough estimates for the different modes.\footnote{
        The counts assessed correspond to the ones reported in \cite{kk_Dronning}, \cite{kk_Gothersgade}, \cite{kk_Gyldenlovesgade}, \cite{kk_Mollegade}, \cite{kk_Norre}, \cite{kk_Peblinge}, \cite{kk_Slotsgade} and \cite{kk_Tagensvej}.
